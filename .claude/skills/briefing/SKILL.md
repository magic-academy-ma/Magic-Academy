# /briefing

현재 세션의 작업 상태를 Done / In progress / Next 형식으로 정리한다.

## 실행 시점

다음 시점에 자동 또는 요청 시 실행한다:
- 기능 또는 컴포넌트가 완료됐을 때
- 작업 방향이 바뀌었을 때
- 세션이 길어져 상태 정리가 필요할 때
- 사용자가 `/briefing`을 입력했을 때

## 출력 형식

```
## 브리핑 — {날짜 HH:mm}

**Done**
- {완료한 작업과 검증 결과}

**In progress**
- {진행 중이거나 막힌 항목, 없으면 "없음"}

**Next**
- {명시적으로 남은 작업, 없으면 "없음"}
```

## 작성 규칙

- Done: 실제로 완료하고 검증까지 끝난 항목만 포함한다. 추측하지 않는다.
- In progress: 시작했지만 완료되지 않은 항목, 또는 블로커가 있는 항목을 적는다.
- Next: 사용자가 명시적으로 요청했거나 계획에 남아 있는 작업만 적는다. 임의로 추가하지 않는다.
- 항목이 없는 섹션은 "없음"으로 표기한다.
