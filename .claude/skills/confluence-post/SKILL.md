# /confluence-post

문서 초안을 받아 메타데이터 블록·§0 개요를 포함한 Confluence 페이지를 생성한다.

## 입력

사용자에게 다음을 확인한다 (이미 제공됐으면 생략):
1. 문서 제목 — `[분류] 문서명` 형식 (예: `[Spec] Event Master Agent 설계`)
2. Confluence 위치 — 상위 페이지 또는 Space (기본: Magic Academy Space)
3. 문서 내용 — 본문 초안
4. 메타데이터 — 상태(Draft/Review/Approved), 작성자, 담당자, 기준 문서(선택)

## 페이지 구조

생성할 페이지는 다음 순서로 구성한다.

**[상단 메타데이터 블록]**

```
> **상태:** {상태}
> **작성자:** @{작성자 Confluence 닉네임}
> **담당자:** @{담당자 Confluence 닉네임}
> **작성일 / 최종 수정일:** {오늘 날짜} / {오늘 날짜}
> **기준 문서:** {관련 문서 링크 — 없으면 생략}
```

**[§0 개요 및 목적]**

```markdown
## 0. 개요 및 목적

이 문서는 {한 줄 요약}.

- **목적**: {이 문서가 해결하는 문제 또는 달성하는 목표}
- **범위**: {이 문서가 다루는 대상 · 단계 · 시스템}
```

**[본문]** — 사용자 제공 초안

**[변경 이력]** — 하단 필수

## 실행 순서

1. 문서 제목·위치·메타데이터를 확인한다
2. 사용자에게 생성할 전체 내용을 보여주고 명시적 승인을 받는다
3. 승인 후 Confluence 페이지를 생성한다 (Atlassian Rovo MCP 사용)
4. 생성된 페이지 URL을 사용자에게 전달한다
   (Discord 공지는 봇이 자동 처리하므로 별도 출력 없음)

## Confluence 페이지 하단에 반드시 추가

변경 이력 테이블을 하단에 포함한다:

```markdown
## 변경 이력

| 버전 | 날짜 | 변경 이력 | 수정자 |
|------|------|-----------|--------|
| v1.0 | {오늘 날짜} | 최초 작성 | @{작성자 Confluence 닉네임} |
```

## 주의

- 페이지 생성은 외부 쓰기 작업이므로 반드시 사용자 승인 후 실행한다
- 시크릿·개인정보·팀원 연락처를 문서에 포함하지 않는다
