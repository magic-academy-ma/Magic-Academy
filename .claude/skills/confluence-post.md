# /confluence-post

문서 초안을 받아 Confluence 페이지를 생성하고 Discord 공지 문구를 출력한다.

## 입력

사용자에게 다음을 확인한다 (이미 제공됐으면 생략):
1. 문서 제목 — `[분류] 문서명` 형식 (예: `[Spec] Event Master Agent 설계`)
2. Confluence 위치 — 상위 페이지 또는 Space (기본: Magic Academy Space)
3. 문서 내용 — 본문 초안

## 실행 순서

1. 문서 제목과 위치를 확인한다
2. 사용자에게 생성할 전체 내용을 보여주고 명시적 승인을 받는다
3. 승인 후 Confluence 페이지를 생성한다 (Atlassian Rovo MCP 사용)
4. 생성된 페이지 URL을 확인한다
5. 아래 Discord 공지 문구를 출력한다

## Confluence 페이지 하단에 반드시 추가

변경 이력 테이블을 하단에 포함한다:

```markdown
## 변경 이력

| 버전 | 날짜 | 변경 이력 | 수정자 |
|------|------|-----------|--------|
| v1.0 | {오늘 날짜} | 최초 작성 | @{작성자 Confluence 닉네임} |
```

## Discord 공지 문구 출력

페이지 생성 완료 후 아래 양식을 채워 코드 블록으로 출력한다.  
Discord MCP 연동이 없으므로 사용자가 직접 붙여넣는다.

```
---
# 문서 생성

## 제목
{문서 제목}

## 위치
{Confluence 경로}

## 링크
{Confluence 문서 URL}

## 내용
- {주요 내용 1}
- {주요 내용 2}
- {주요 내용 3}

## 참고 사항
- 문서 상태: Draft (팀 검토 후 승인 예정)
- 비고:
  - (필요 시 작성)

## Reviewer
- (검토하신 분께서 :thumbsup: 이모지 달아주세요)
---
```

## 주의

- 페이지 생성은 외부 쓰기 작업이므로 반드시 사용자 승인 후 실행한다
- 시크릿·개인정보·팀원 연락처를 문서에 포함하지 않는다
- 기존 페이지 수정이 아닌 신규 생성 시에만 Discord 공지를 출력한다
