# MBTI → Big Five 초기값 및 허용 범위

이 정책은 심리검사 환산식이 아니라 Magic Academy의 제품 규칙이다. 값은 `-50~+50` 범위의 5단위이며, Low는 -50~-20, Neutral은 -15~+15, High는 +20~+50으로 해석한다.

각 칸은 `최솟값 / 기본값 / 최댓값`이다.

| MBTI | 개방성 | 성실성 | 외향성 | 우호성 | 정서 안정성 |
| --- | --- | --- | --- | --- | --- |
| ISTJ | -45 / -25 / +5 | -15 / +25 / +45 | -45 / -25 / +5 | -45 / -20 / +15 | -50 / 0 / +50 |
| ESTP | -45 / -25 / +5 | -45 / -25 / +15 | -5 / +25 / +45 | -45 / -20 / +15 | -50 / 0 / +50 |
| INFP | -5 / +25 / +45 | -45 / -25 / +15 | -45 / -25 / +5 | -15 / +20 / +45 | -50 / 0 / +50 |
| ENTJ | -5 / +25 / +45 | -15 / +25 / +45 | -5 / +25 / +45 | -45 / -20 / +15 | -50 / 0 / +50 |
| ESFJ | -45 / -25 / +5 | -15 / +25 / +45 | -5 / +25 / +45 | -15 / +20 / +45 | -50 / 0 / +50 |

## 설정·검증 규칙

1. 기존 Student와 MBTI를 선택한다.
2. 선택한 MBTI의 기본값으로 Big Five를 초기화한다.
3. 허용 범위 안에서 5단위로 조절한다.
4. MBTI를 바꾸면 이전 조절값을 버리고 새 기본값으로 전부 초기화한다.
5. 클라이언트와 서버는 같은 규칙으로 검증하며 잘못된 값을 자동 보정하지 않는다.
6. 시뮬레이션 시작 시 MBTI·Big Five·성격 설명·규칙 버전과 성격 관련 초기 Memory를 잠근다.
7. 시작 후에는 잠금 해제, 일반 Student로 복원, 사용자 요청에 의한 성격 Memory 재작성을 허용하지 않는다.

구체 요청·응답과 저장 계약은 비공개 API 명세와 데이터 모델에서 관리한다.

## Runtime 해석

- MBTI는 말투·정보 인식·판단·생활 스타일의 정성적 지침이다.
- Big Five는 행동 후보 선호도와 표현 강도를 조절한다.
- 성격은 상태·관계·Memory·일정·Event를 무시하고 행동을 강제하지 않는다.
- Policy Engine은 Runtime 결과에 이미 반영된 성격 영향을 delta에 다시 가산하지 않는다.
