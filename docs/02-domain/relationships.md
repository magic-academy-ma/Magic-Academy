# 관계 (Relationship)

> **관계는 Agent 간의 연결이다.**

---

## 관계 척도

Agent 쌍마다 아래 6개 척도를 독립적으로 보유한다.

| 척도 | 설명 | 변화 방향 |
|------|------|----------|
| 호감도 | 상대에 대한 감정적 선호 | 긍정 사건 ↑, 갈등 ↓ |
| 친밀도 | 얼마나 가까이 지내는지 | 같은 조직·반복 상호작용 ↑ |
| 신뢰도 | 믿을 수 있는 정도 | 약속 이행 ↑, 배신 ↓ |
| 긴장도 | 갈등·불편함의 수준 | 충돌 사건 ↑, 화해 ↓ |
| 경쟁 | 서로를 경쟁 상대로 인식하는 정도 | 성적·장학금 비교 ↑ |
| 의존도 | 상대에게 기대는 정도 | 도움 수혜 ↑, 독립 행동 ↓ |

---

## 관계 유형

척도 조합의 결과로 관계 유형이 결정된다 (구체적 임계값은 구현 시 설계).

| 유형 | 설명 |
|------|------|
| 친구 | 호감도·친밀도 모두 높음 |
| 선후배 | 학년 차이 + 의존도·신뢰도 기반 |
| 라이벌 | 경쟁 높음, 긴장도 중간 이상 |
| 고백 | 호감도 임계값 초과 + 특정 사건 트리거 |
| 배신 | 신뢰도 급락 사건 발생 |
| 화해 | 긴장도 → 0 전환 사건 발생 |

---

## 관계 변화 규칙

### 소속 기반 (조직 → 관계)
- **같은 조직 소속이면 친밀도 UP** (기숙사·동아리·전공·총학생회 공유 시 적용)

### 사건 기반 (사건 → 관계)
- 긍정 사건(조별과제 성공, MT, 축제): 호감도·친밀도 ↑
- 경쟁 사건(중간·기말고사 성적 비교): 경쟁 ↑, 상황에 따라 긴장도 ↑
- 갈등 사건(배신, 교수님 납치): 신뢰도 ↓, 긴장도 ↑
- 화해 사건: 긴장도 ↓

### 내부 상태 기반 (Agent 상태 → 관계)
- 스트레스·피로도 높음: 관계 척도 변화폭 확대 (부정 방향으로 민감)
- 기분 좋음: 호감도·친밀도 변화 시 긍정 방향 가중

---

## 관계 저장 구조 (설계 참고)

- Agent 쌍 (A, B) 단위로 저장
- 방향성 고려 필요: A→B 호감도 ≠ B→A 호감도
- 관계 이력은 memory 상한(10)과 별도로 관리 (미확정 → `what-is-pending.md`)
