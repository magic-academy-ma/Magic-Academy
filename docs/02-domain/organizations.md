# 조직 (Organization)

> **조직은 관계가 생기는 맥락이다.**

---

## MVP 조직 목록

| 조직 유형 | 수량 | 특징 |
|----------|------|------|
| 기숙사 | 2개 | 생활 공간 공유 → 친밀도 강하게 ↑ |
| 동아리 | 3개 | 관심사 기반 소속 |
| 전공 | 4개 | 수업·조별과제·성적 경쟁의 단위 |
| 총학생회 | 1개 (4~5명) | 전교 단위 사건(축제 등)의 주관 |

---

## 소속 규칙

### 배정 방식

| 조직 | 배정 방식 |
|------|----------|
| 전공 | 4개 전공 × 학생 5명 = 20명. 학년(1~4학년)은 전공별 랜덤 배정 |
| 기숙사 | 기숙사 2개 중 1개에 랜덤 배정 |
| 동아리 | 0개 또는 1개 (선택적 가입, 시뮬레이션 초기 또는 사건으로 결정) |
| 총학생회 | 전체 20명 중 4~5명 선발 |

### 친밀도 규칙

- **같은 조직에 소속된 Agent 쌍은 초기 친밀도 보너스를 받는다**
- 조직이 많이 겹칠수록 친밀도 보너스 누적 (기숙사 + 동아리 동시 소속 등)

---

## 조직과 공간의 관계

| 조직 | 주요 활동 공간 |
|------|--------------|
| 전공 | 교실, 연구실 |
| 기숙사 | 기숙사 (저녁·주말) |
| 동아리 | 동아리방 (명시적 정의 미정) |
| 총학생회 | 학생회관 (명시적 정의 미정) |

---

## 확장성 메모 (MVP 제외)

- 단과대학 확장: 전공 4개 → N개
- 조직 수 확장: 동아리·기숙사 수 조정
- 인간-동물 관계 확장 등

구현 시 조직을 하드코딩하지 않고 확장 가능한 구조로 설계할 것.
