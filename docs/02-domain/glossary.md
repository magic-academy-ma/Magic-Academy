# 용어집 (Glossary)

> 이 파일은 Magic Academy 전체 도메인의 공용 용어를 정의한다.  
> 새 용어가 추가되면 이 파일도 업데이트한다.

---

## A

| 용어 | 정의 |
|------|------|
| **Agent** | 시뮬레이션 내 자율적으로 행동하는 단위. Student · Professor · Event Master · Magic Agent |
| **내부 상태** | 각 Agent가 보유하는 배고픔·피로도·스트레스·만족도·기분 값. 행동과 관계 변화의 입력 |

## E

| 용어 | 정의 |
|------|------|
| **Event (사건)** | 관계와 조직을 변화시키는 트리거. 정기·비정기·배경 사건으로 분류 |
| **Event Master Agent** | 매 Tick마다 사건을 생성하는 오케스트레이터. MVP 포함 확정. |

## M

| 용어 | 정의 |
|------|------|
| **memory 상한** | Student Agent가 보유할 수 있는 memory 최대 개수. MVP 기준 10 |

## O

| 용어 | 정의 |
|------|------|
| **Organization (조직)** | 관계가 생기는 맥락. 기숙사·동아리·전공·총학생회 |

## P

| 용어 | 정의 |
|------|------|
| **Professor Agent** | 교수 역할 Agent. 교양 1 + 전공 4 = 5명. 수업·시험·과제 사건 진행 |

## R

| 용어 | 정의 |
|------|------|
| **Relationship (관계)** | Agent 간 연결. 척도(호감도·친밀도·신뢰도·긴장도·경쟁·의존도)와 유형(친구·라이벌 등)으로 표현 |

## S

| 용어 | 정의 |
|------|------|
| **Student Agent** | 학생 역할 Agent. 20명. 시뮬레이션의 주체 |

## T

| 용어 | 정의 |
|------|------|
| **Time Tick** | 시뮬레이션 시간 단위. 1 Tick = 24분 = 1일 (확정) |
| **3축** | Magic Academy 시뮬레이션을 구동하는 핵심 프레임: 관계·조직·사건 |

## U

| 용어 | 정의 |
|------|------|
| **User Persona Agent** | 사용자가 성격·성향을 지정하는 플레이어 Agent. 1명. 사용자 개입은 이 Agent에만 영향 |

## 배경 관련

| 용어 | 정의 |
|------|------|
| **배경 (Context)** | 시간·공간·날씨·학기 등 3축이 돌아가는 무대. 3축에 영향을 주지만 스스로 방향을 만들지 않음 |
| **장학금** | 기말고사 성적 상위 Agent에게 부여. 경쟁 관계 ↑ 트리거 |
