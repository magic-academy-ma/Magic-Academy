# 시간과 공간 (배경)

> 배경은 3축(관계·조직·사건)이 돌아가는 무대다.  
> 배경은 3축에 영향을 주지만, 스스로 방향을 만들지 않는다.

---

## 시간 (Time Tick)

### Tick 정의

| 항목 | 값 | 상태 |
|------|----|------|
| 1 Tick = | 24분 (실제 시간) | **잠정 확정** — 최종 확정 미정 |
| 시뮬레이션 상 1일 = | 1 Tick | |
| 밤 시간 | 스킵 가능 | |
| 시작 시점 | 입학일 | |

> **미정**: Time Tick 최종 단위, 이벤트 발생 빈도 → `what-is-pending.md`

### 시간 구분

| 시간대 | 내용 |
|--------|------|
| 수업 시간 | 교수-학생 상호작용, 조별과제, 출석 |
| 점심 시간 | 식당 이동, 관계 상호작용 |
| 방과 후 | 동아리, 자유 시간, 도서관 |
| 밤 시간 | 스킵 (피로도 회복) |

### 학사 일정

한국식 학기제 기반.

| 이벤트 | 시기 |
|--------|------|
| 개강 | 학기 시작 |
| MT | 학기 초 |
| 중간고사 | 학기 중반 |
| 기말고사 | 학기 말 |
| 축제 | 학기 1회 |
| 장학금 발표 | 기말고사 후 |

---

## 공간

| 공간 | 주요 활동 |
|------|----------|
| 교실 | 수업, 조별과제 |
| 식당 | 식사 (배고픔 감소), 자유 관계 상호작용 |
| 도서관 | 자습, 스터디, 시험 준비 |
| 연구실 | 교수-학생 상호작용, 특수 사건 |
| 기숙사 | 저녁·주말, 기숙사 소속 Agent 친밀도 ↑ |

---

## 날씨

- 랜덤 날씨 발생
- 주요 사건(이벤트) 전 징조 역할: 날씨 변화 → 분위기 힌트 제공
- 날씨 자체가 관계를 바꾸지는 않으나, 사건 발생 확률·분위기에 영향

---

## 학교 운영

- **장학금**: 기말고사 성적 상위 N명에게 부여 → 경쟁 관계 ↑
- **상/벌점**: 사건 결과에 따라 부여 (구체 기준 미확정)
