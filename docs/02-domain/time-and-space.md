# 시간과 공간 (배경)

> 배경은 3축(관계·조직·사건)이 돌아가는 무대다.  
> 배경은 3축에 영향을 주지만, 스스로 방향을 만들지 않는다.

---

## 시간 (Time Tick)

### Tick 정의

| 항목 | 값 | 상태 |
|------|----|------|
| 1 Tick = | 8분 (실제 시간) = 1블록 | 확정 |
| 시뮬레이션 상 1일 = | 3블록 = 24분 | 확정 |
| 활동 블록 | MORNING · AFTERNOON · EVENING | 확정 |
| 밤 시간 | 스킵 (야간 회복 Policy 적용) | 확정 |
| 시작 시점 | 입학일 | |

> **미정**: 이벤트 발생 빈도 → `what-is-pending.md`

### 시간 구분

| 블록 | 주요 활동 |
|------|----------|
| MORNING (아침) | 수업, 교수-학생 상호작용 |
| AFTERNOON (오후) | 조별과제, 식당, 관계 상호작용 |
| EVENING (저녁) | 동아리, 자유 시간, 도서관 |
| 밤 | 스킵 — 야간 회복 Policy 적용 후 다음 날 MORNING 전환 |

> **미정**: 각 블록 세부 시간 범위 및 Event 매핑 → `what-is-pending.md`

### 학사 일정

한국식 학기제 기반.

| 이벤트 | 시기 |
|--------|------|
| 개강 | 학기 시작 |
| MT | 학기 초 |
| 중간고사 | 학기 중반 |
| 기말고사 | 학기 말 |
| 축제 | 학기 1회 |
| 장학금 발표 | 기말고사 후 |

---

## 공간

| 공간 | 주요 활동 |
|------|----------|
| 교실 | 수업, 조별과제 |
| 식당 | 식사 (배고픔 감소), 자유 관계 상호작용 |
| 도서관 | 자습, 스터디, 시험 준비 |
| 연구실 | 교수-학생 상호작용, 특수 사건 |
| 기숙사 | 저녁·주말, 기숙사 소속 Agent 친밀도 ↑ |

---

## 날씨

- 랜덤 날씨 발생
- 주요 사건(이벤트) 전 징조 역할: 날씨 변화 → 분위기 힌트 제공
- 날씨 자체가 관계를 바꾸지는 않으나, 사건 발생 확률·분위기에 영향

---

## 학교 운영

- **장학금**: 기말고사 성적 상위 N명에게 부여 → 경쟁 관계 ↑
- **상/벌점**: 사건 결과에 따라 부여 (구체 기준 미확정)
