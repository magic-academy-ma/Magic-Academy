# 사건 (Event)

> **사건은 관계와 조직을 변화시키는 트리거다.**

---

## MVP 사건 목록

| 사건 | 주기 / 트리거 | 주요 효과 |
|------|-------------|----------|
| 수업 (시간표) | 매 Tick (학사 일정) | 교수-학생 관계, 피로도·스트레스 누적 |
| 조별 과제 | 학기 중 발생 | 협력 → 친밀도·신뢰도 ↑, 갈등 시 긴장도 ↑ |
| 과팅 / 미팅 | 비정기 | 호감도 변화, 새 관계 형성 |
| MT | 학기 초 | 친밀도 대량 ↑, 기숙사·동아리 단위 주로 발생 |
| 중간·기말고사 | 학기 중 2회 | 스트레스 누적, 성적 → 장학금 결정, 경쟁 ↑ |
| 축제 | 학기 1회 | 전교 단위 사건, 다양한 관계 교차, 총학생회 주관 |
| 교수님 납치 | 특수 트리거 | 범인과 공모자 관계 변화, 대학원 직행 결과 |
| 랜덤 날씨 | 배경 기반 | 이벤트 전 징조 제공, 분위기 전환 |

---

## 사건 발생 구조

### 사건 분류

| 분류 | 설명 | 예시 |
|------|------|------|
| 정기 사건 | 학사 일정에 따라 고정 발생 | 수업, 중간·기말고사 |
| 비정기 사건 | 조건 충족 또는 랜덤으로 발생 | 과팅, 교수님 납치 |
| 배경 사건 | 다른 사건의 징조나 분위기 제공 | 랜덤 날씨 |

### 사건 발생 빈도

> **미정** — Time Tick 최종 확정과 함께 결정 예정 (`what-is-pending.md` 참조)

### Event Master Agent (미정)

매 Tick마다 사건을 생성·오케스트레이션하는 전담 Agent.  
MVP 포함 여부 미확정 → `what-is-pending.md` 참조.

## 사건과 관계 변화 매핑 (대략)

| 사건 | 관계 변화 |
|------|----------|
| 조별 과제 성공 | 팀원 간 친밀도·신뢰도 ↑ |
| 조별 과제 갈등 | 팀원 간 긴장도 ↑ |
| MT | 조직 내 친밀도 ↑ |
| 중간·기말 성적 차이 | 경쟁 ↑ (성적 높은 쪽이 낮은 쪽에 비해) |
| 고백 사건 | 호감도 임계값 초과 시 트리거, 성공/실패에 따라 관계 유형 변화 |
| 배신 사건 | 신뢰도 급락, 긴장도 ↑ |
| 화해 사건 | 긴장도 → 0, 호감도 소폭 ↑ |

---

## 확장성 메모 (MVP 제외)

- 사건 규모 확장 (전교·외부 사건)
- 사건 타입 추가: 연구실 인턴, 동아리 공연, 교환학생 등
- 사건은 하드코딩하지 않고 타입 기반 확장 가능 구조로 설계할 것
