# 미정 사항

> **AI는 이 항목들을 임의로 확정하지 않는다.**  
> 해당 항목이 작업에 걸리면 사용자에게 먼저 확인한다.

---

## 설계 미정

> 출처: [Spec] MVP 핵심 설계 기준 §5.3 미결 안건 (Confluence #6356994)

| 항목 | 현재 상태 | 비고 |
|------|----------|------|
| Time Tick 단위 최종 확정 | 잠정: 24분 = 1일 | 이벤트 발생 빈도와 함께 결정 |
| 이벤트 발생 빈도 | 미정 | Time Tick과 연동 |
| Reflection 트리거 조건 | 미정 | A(하루 종료 전체) / B(importance 합계 threshold) / C(큰 사건 참여자만) 중 택1 |
| Memory 초과(10개) 처리 전략 | 미정 | 요약 / 삭제 / importance 기반 압축 중 택1 |
| 관계 수치 변화량 공식 | 미정 | 단순 delta 가산 vs LLM 판단 위임 |
| tick 3블록 시간대 상세 | 미정 | 아침/오후/저녁 각 블록 시간 범위 및 Event 매핑 |
| Agent 초기값 배정 방식 | 미정 | 이름·성격·조직: 랜덤 생성 vs 사전 정의 파일 |
| 프롬프트 캐싱 구현 시점 | 미정 | Week 3~4 포함 vs Week 5~6 고도화 |
