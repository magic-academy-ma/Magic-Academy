# 미정 사항

> **AI는 이 항목들을 임의로 확정하지 않는다.**  
> 해당 항목이 작업에 걸리면 사용자에게 먼저 확인한다.

---

## 설계 미정

| 항목 | 현재 상태 | 비고 |
|------|----------|------|
| Time Tick 단위 최종 확정 | 잠정: 24분 = 1일 | 이벤트 발생 빈도와 함께 결정 |
| 이벤트 발생 빈도 | 미정 | Time Tick과 연동 |
| Event Master Agent MVP 포함 여부 | 미정 | 매일 사건을 생성하는 오케스트레이터 역할 |
| 토큰 비용 절감 전략 | 미정 | memory 상한·tick 빈도·요약 전략 등 |
| Agent 간 통신 구조 | 미정 | 기술 스택 결정 후 설계 |
