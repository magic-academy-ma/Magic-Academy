# 미정 사항

> **AI는 이 항목들을 임의로 확정하지 않는다.**  
> 해당 항목이 작업에 걸리면 사용자에게 먼저 확인한다.

---

## 설계 미정

> 출처: [Spec] MVP 핵심 설계 기준 §5.3 미결 안건 (Confluence #6356994)

| 항목 | 현재 상태 | 비고 |
|------|----------|------|
| 이벤트 발생 빈도 | 미정 | — |
| Reflection 트리거 조건 | **확정** | C — 큰 사건(importance >= threshold) 참여자만. threshold는 설정 파일로 관리. 추후 B(합산) 방식으로 전환 가능하도록 설계. |
| Memory 초과(10개) 처리 전략 | **확정** | importance 기반 압축 |
| 관계 수치 변화량 공식 | **확정** | 단순 delta 가산. Agent의 Generate Intent 노드에서 자연어로 관계 맥락 포함해 표현력 보완. 추후 LLM 판단 위임으로 확장 가능. |
| tick 3블록 시간대 상세 | 미정 | 아침/오후/저녁 각 블록 시간 범위 및 Event 매핑 |
| Agent 초기값 배정 방식 | 미정 | 이름·성격·조직: 랜덤 생성 vs 사전 정의 파일 |
